# Sample workspace: Northwind Bikes (invented)

Everything in this folder is invented for the sample. "Northwind Bikes" is a made-up bicycle shop, and its six projects
are fictional. Nothing here describes a real company, client or product. The sample is what `node serve.mjs --sample`
builds into a temporary folder, so the map has something to show before you point Overmap at your own vault.

Layout:

- `notes/<project>.md`: the vault project notes (frontmatter the registry reads, plus a `## Blockers` section).
  The `@PROJECTS@` placeholder in `path` is replaced with the temporary projects folder when the sample is built.
- `<project>/PLAN.md`: the plan the cockpit reads (percentages shown on the map).
- `<project>/test-results.json`: one run each. `shop-api` has two failing tests on purpose.
- `<project>/graphify-out/graph.json`: a small synthetic code graph. `storefront` has none on purpose ("No graph yet").

Groups: **Shop** (storefront, shop-api, api-worker), **Studio** (mobile-app, docs-site), **Internal** (ops-tool).
`api-worker` is a git worktree of `shop-api`. The graphs are regenerated by `node examples/make-graphs.mjs`.
